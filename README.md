# House Price Prediction with Linear Regression
Oasis Infobyte Data Analytics Internship, Level 2, Task 1

## Overview
Predicts house prices using Linear Regression on a Seattle housing dataset (4600 rows).

## Steps
1. EDA, cleaning (invalid prices/rooms, outliers)
2. Feature engineering (house_age, was_renovated)
3. Correlation heatmap, One-Hot Encoding of city
4. 80/20 split, StandardScaler, Linear Regression
5. Evaluation: MSE, RMSE, R2, residual plots, coefficient analysis
6. Bonus: Ridge and Lasso comparison
